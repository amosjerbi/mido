OSCILLATOR
Shortcuts
  • Space Play or pause
  • Pills Switch layers or play them all together
  • Arrows Move the cursor
  • Enter Fill current step with selected note
  • Delete Clear current step
  • R Randomize the current layer
  • F Fill the current column
  • G Fill the current row
  • C Clear the current layer
  • Z / X Previous or next note
  • - / + Decrease or increase BPM
  • 1 - 8 Select a note button
